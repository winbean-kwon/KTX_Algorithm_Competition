# 제 2회 KRT 주식 투자 알고리즘 경진대회

## 주제

자본시장 데이터 및 공공 데이터를 활용하여 Long-Short 포트폴리오 구성

## 최종 제출 과정

상위 200종목, 하위 200종목을 매일 거래한다면, 너무 많은 종목이니 시장의 흐름이라도 따라가야겠다고 생각했습니다.
- 변동성을 줄이기 위해 상관관계가 있는 보조지표를 사용하려했습니다.
- 추세를 타는 지표를 찾고자 하였고, MACD, 이평선 OBV, RSI 등등 많은 지표들을 테스트해 본 결과 RSI가 가장 기대치에 부합하였습니다.
- 여기서 보조지표를 여러개 활용해보는게 좋겠다는 아이디어가 나왔고, 2~3개씩 묶어본 결과 RSI와 샤프지수를 결합하는게 가장 효과적이었습니다.
- ARIMA 모델도 활용해보니 test dataset에서 유의미한 결과가 있어 추가하였습니다.
- RSI 지표와 샤프지수는 결과값의 범위가 다르기에 -1~1값으로 통일 후, rsi, sharpe, arima 결과값을 다 더했을 때 높은 것으로 분류하였습니다.
- 주어진 데이터의 기간을 통해 나눠서 진행하였고 결과는 장기적으로 상승하거나 하락하는게 큰 변동없이 방향성을 유지하였습니다.
- 기간이 너무 길어 과거 변동성이 컸던 종목들이 순위에 영향을 미치지 않을까싶어 기간별로 가중치를 두었습니다.
